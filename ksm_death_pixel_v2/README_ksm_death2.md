**动作**参考 `ksm_death/`（82 帧 AI 生成序列，只取节奏），**角色本体与配色**取自官方原生像素画
`D:/bang/nfc/ksm/12.png`（640×640 / 块宽 10px / 原生 64×64 / 21 色）。

与 v1（`ksm_death_pixel/`）的本质区别：

|  | v1 | v2 |
|---|---|---|
| 角色造型/比例 | 跟着 AI 图走（把 AI 帧重像素化） | 官方 12.png 的像素块重组 |

| 画布 | 72 原生 / cell 84 | **64 原生 / cell 76（与 `ksm_hurt_pixel` 一致）** |

| 06-07 | **伏倒定格**（正面跪伏、头深低盖住上身、闭眼、吉他横抱身前）×2 | 官方块重新摆位：腿回跪位、上身 +4、头 +11/+2 | f044-058（AI 稳定 15 帧） |

> v3 关键修正：**删掉 v2 的"空中腾飞"帧**（AI 全序列底行持续触地，无腾空）；**补上 AI 的伏倒定格阶段**（f044-058 停了 15 帧，v2 完全缺失）；头不再"后甩"（AI 里头一路往右下低）；星星改左上飘（v2 是竖直上升）。

## 处理管线

1. **官方块切分**：头 `y23-41 / x19-42`、上身+吉他+手臂 `y42-56 / x19-47`、大腿+袜+鞋 `y57-63 / x26-36`。
2. **帧 02-05**：腿不动，上身 +1/+2/+2/+3 下沉，头 dx **+1/+1/+2/+2**、dy **+1/+2/+3/+5**（持续往右下低，无后甩）。**取消 v2 的膝盖外翻/鞋外撇** —— AI 蜷缩期腿完全不动。
3. **帧 06-07 伏倒定格**：腿平移回跪位（小腿贴地）、上身穿原位下沉 4 格（y46-60）、头下移 11 格右移 2 格（y34-53）盖住上身顶部、闭眼。**不复制头顶弧做"披发"** —— 实测会形成双头顶，正面视角无法用现有块表达头发披落，按 Q 版简化只保留"头深低"。
4. **帧 08**：翻身弓身（臀先触地，脚仍弓着）→ **帧 09-10**：放平贴地。对应 AI 的 f059→f060。
5. **帧 11-16**：帧 10 + 白色十字星（E 白 5×5 主星 + 3×3 小星 + 单点余光）；星群质心从原生 **(40,53) 移到 (19,24)**（左上），末端用浅紫 N 余光收尾。
6. **吉他全程在怀**：站立斜抱 → 伏倒时横抱身前 → 翻身/躺平时横压身上，琴头与三色弦钮（黄 P / 品红 S / 蓝 U）探在脚边。

## 质检（`qc_ksm_death2.py`，数值判据）

- 帧 01 与 12.png 不透明区 **RGB 全等**（逐像素）
- 全序列 21 色内、无越界色；alpha 二值
- 内容不溢出 padding 区（避免 Unity 切图串帧）
- **全部 16 帧**底行必须触地（AI 序列无腾空帧）
- 帧 01-10 单连通域（无悬空碎块）；帧 11-16 ≤5 个连通域（身体 + 星点）
- 帧 11-16 身体像素与帧 10 **完全一致**，只有白 / 浅紫星色像素可自由增减（星星会移动）

## Unity 导入

- Sprite Mode = **Multiple**，Grid By Cell Size = **76 × 76**
- Filter Mode = **Point (no filter)**，Compression = **None**
- Pivot = **Bottom Center**
- PPU：与 `ksm_hurt_pixel` **同一 PPU**（同为 12.png、同为块宽 10px、同为 cell 76）

## 已知限制

- 本轮会话的模型**不能直接看图**，造型由字符栅格 + 数值质检保证。**建议人工目检 GIF / sheet**；需要微调时改 `make_ksm_death2.py` 里的坐标后复跑即可（参数全在文件顶部与帧函数内，一键复现）。
- 帧 05 → 06 是**伏倒**的快速一跳（12fps 下单帧 83ms）：头一次性下沉 6 格。AI 在 f042→f044 之间也只有 1 帧过渡（f043），节奏相当；若嫌跳，可把帧 05 的头再往下压 2 格。
- 伏倒帧（06-07）没有"头发披落"层：正面视角下复制官方头顶弧会变成双头顶（已实测），按 Q 版简化处理。
- GIF 预览为循环播放（便于反复审查），游戏内应设为 `loop=false`。
