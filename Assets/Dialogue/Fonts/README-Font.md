# 字体来源与授权

## Fusion Pixel Font（缝合像素字体）

- 用途：对话气泡与 NPC 交互提示的中文/拉丁文本渲染。
- 文件：`fusion-pixel-font-12px-proportional-zh_hans.ttf`
  - 规格：12px、比例模式（proportional）、简体中文（zh-Hans）字形。
- 来源：<https://github.com/TakWolf/fusion-pixel-font>
  - 版本：Release `2026.10.25`
  - 直链：`https://github.com/TakWolf/fusion-pixel-font/releases/download/2026.10.25/fusion-pixel-font-12px-proportional-ttf-v2026.10.25.zip`
- 授权：**SIL Open Font License 1.1**（字体部分）
  - 许可全文见同目录 `LICENSE-FusionPixel-OFL.txt`（取自上游仓库根目录 `LICENSE-OFL`）。
  - OFL-1.1 允许随软件一并打包、嵌入与再分发；不得单独出售字体文件，衍生版本须保留同名许可与版权声明。
- 上游字体许可（见仓库 README）：Ark Pixel Font、MisekiBitmap、BoutiqueBitmap、Cubic 11、Galmuri 等均为 OFL-1.1；构建程序为 MIT。

## 使用范围说明

- 本项目只把该字体用于游戏内文本的 TMP Font Asset 烘焙，未修改字形。
- 未改动全局 TMP 默认字体（仍是 LiberationSans SDF），因此既有 HUD 文本不受影响。
